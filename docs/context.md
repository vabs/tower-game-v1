# Project Context

Updated: 2026-11-09

## Overview
A modern-military pixel-art tower defence game for desktop browsers: Canvas playfield, DOM panels, Vite build to a single `dist/index.html`. 50 levels, 30 towers (6 families, 5 upgrade levels each), 20 enemy types plus 4 boss variants, medals and a local save.

## Status
Milestones M0-M5 of `docs/plans/2026-11-06-playable-game-plan.md` are done: the full campaign is playable (start screen, level select with locks and medals, pause with analytics, level complete, game over, game end), all towers/upgrades/sell/targeting work, game speed 1x/2x/3x, auto-pause on blur, VFX, a balance bot and a tuned difficulty curve. `npm test`, `npm run smoke` and `npm run build` are green. Balance numbers and the before/after table are in `docs/plans/2026-11-06-balance-review.md`.

## Architecture
The simulation is pure and deterministic (fixed step 1/60 s, seeded RNG, no DOM, no wall clock), so it runs headless in tests and in the balance bot. The renderer and UI only read the world and send commands.

- `src/sim/` world (`createWorld`, `step`), `spawner`, `enemies`, `towers`, `projectiles`, `damage`, `effects` (slow, burn, stun, marks, gas fields, chain lightning), `auras`, `commands` (place, upgrade, sell, set targeting, start wave), `stats` (run analytics), `sandbox`, `map`.
- `src/data/` pure data: `towers` (30 towers; upgrade costs generated by `tools/upgrade-costs.mjs`), `enemies`, `bosses`, `levels` (50 levels: map type, combat waves, supply drops, boss, unlocks), `waves` (wave builder, `levelScaling`, `LEVEL_TUNE`, `BOSS_TUNE`), `maps`.
- `src/systems/` `targeting` (first/last use remaining distance to the exit; closest; strongest; `air` for anti-air), `economy` (stipend, +15% in-combat upgrade surcharge), `waves`, `collision`.
- `src/core/` grid, path, rng, fixed-step clock (with speed multiplier and a step cap per frame), save (localStorage, versioned), medals.
- `src/render/` canvas renderer (map layer, markers, enemies, towers, projectiles, fx) and sprite loader; cosmetic effects run on a clock scaled by game speed.
- `src/ui/` `hud` (top bar, tower list, selected panel, mission brief), `screens` (overlays), `input` (mouse, Esc, 1/2/3, N in sandbox), `analytics`.
- `src/audio/` runtime-synthesized sound (app layer only; the sim never imports it): `engine` (lazy AudioContext on first gesture, music/sfx buses, compressor, mute/duck), `synth` (instruments), `music` (look-ahead scheduler, crossfade, stings), `tracks` (music as data, schema in its header), `trackSchema`, `notes` (parsers), `musicState` (game state -> track), `sfx` (event -> sound map and voices), `limiter` (voice limits), `index` (controller used by `main.js`). Sim `fire` events exist only for audio.
- `src/game/state.js` screen state machine; `src/main.js` boot, game loop, speed, auto-pause.
- `tools/` `smoke.mjs` (Playwright), `balance.js` + `balance-bot.js` (bot), `autotune.mjs`, `upgrade-costs.mjs`, sprite generators (Python). Tower sprites come from `generate_tower_assets.py`: isometric 3D scenes ray-cast to 24x24 pixel art, with the level shown by trim colour (L1 plain, L2 bronze, L3 silver, L4 gold, L5 violet with a glowing band) plus new modules and barrels. `generate_pixel_assets.py` no longer draws towers.
- `tests/` vitest suites for sim, data, save, targeting, clock, upgrade-cost efficiency.

## Key rules
- Only the Anti-Air family hits air; AA does 60% damage to ground. Air units fly a straight line from spawn to goal.
- Targeting modes: first, last, closest, strongest, and `air` (air first, then closest to exit; AA towers default to it).
- Vulnerability (Target Painter + Armor Breaker, additive, strongest of each kind) applies to direct hits, burn and gas.
- A tower owns at most one live gas field. Shock Coil `chains` is the total number of targets hit.
- Economy: starting coins `200 + 25 * (level - 1)`, kill coins per enemy, end-wave stipend `10 + floor(level / 2)`, supply-drop waves on some levels, early-call bonus 1 coin per 2 s left on the countdown (7 s countdown).
- Enemy HP per level: `(1 + 0.03 * (level - 1)) * LEVEL_TUNE[level - 1]`; bosses also `* BOSS_TUNE`. Boss base HP is 6x (ground) / 4x (air) the base enemy; a leaking boss takes 25 HP.
- Upgrade costs follow one formula: every upgrade buys 85% of the power per coin of a fresh L1 of the same tower.

## UI additions (gameplay pass 1)
Next-wave preview card (`ui/wavePreview.js`), tower tooltips and upgrade deltas (`ui/towerInfo.js`), aura highlight/buff pips/mark reticles, floating coin text, leak flash, wave/boss/supply banners, hotkeys (`ui/hotkeys.js`: Space, U, S/Delete, T, Tab), and Recruit/Regular/Veteran difficulty (`core/difficulty.js`, world option `difficulty`; Veteran HP x1.40, Recruit HP x0.75 and +25% coins; saved in the save file, missing means Regular).

## Gameplay pass 2
Human-proxy bot profile (`tools/balance-bot.js` options `buildOnly`, `placement`, `firstOnly`, `difficulty`; `HUMAN_PROFILE`), `tools/balance.js --profile human --difficulty --seed0`, parallel `tools/sweep.mjs`, autotune fitting both profiles (see the Follow-up in `docs/plans/2026-11-06-difficulty-review.md`; Veteran is HP x1.40). Boss phases (`sim/bossPhases.js`: escorts below 50% HP, enrage +20% speed below 25%, `bossPhase` events). Optional contracts (`sim/contracts.js`, tracker in `world.stats.contract`, save field `contracts`). The mission card in the right panel folds away once wave 1 starts, so the right panel has no hidden overflow at 1280x720 (smoke asserts it).

## How to run
- `npm install`, `npm run dev`
- `npm test`, `npm run smoke`, `npm run build` (open `dist/index.html`), `npm run balance`
- `?level=N` and `?sandbox=1` URL shortcuts (see README)
